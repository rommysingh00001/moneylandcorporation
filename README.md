# Moneyland Verified — Static HTML Frontend

Mobile-first static frontend for the Moneyland Verified Gurgaon property portal.

## Pages
- `index.html` — Home
- `properties.html` — Property listing/search
- `property-detail.html` — Property detail
- `list-property.html` — Owner listing form
- `owner-dashboard.html` — Owner dashboard
- `verification.html` — Moneyland verification timeline
- `login.html` — Login placeholder
- `admin.html` — Admin verification queue
- `styles.css` — Shared responsive styling
- `app.js` — Small frontend interactions
